# 15. 3Sum

**Difficulty:** Medium

**Topic:** Array, Sorting, Two Pointers, Duplicate Handling

## 🧠 Problem Understanding

Given an integer array `nums`, return all unique triplets `[nums[i], nums[j], nums[k]]` such that:

- `i != j`, `i != k`, and `j != k`.
- The sum of all three elements must equal `0`.
- The result must not contain duplicate triplets.

## Example 1

**Input:**
```text
nums = [-1, 0, 1, 2, -1, -4]
```

**Output:**
```text
[[-1, -1, 2], [-1, 0, 1]]
```

**Explanation:**

- `-1 + -1 + 2 = 0`
- `-1 + 0 + 1 = 0`

These are the unique triplets whose sum is zero.

---

## Approach: Sorting + Two Pointers

### Intuition

We need to find three numbers whose sum is equal to zero.

Instead of using three nested loops, we can optimize the solution using Sorting + Two Pointers.

First, sort the array. Then fix one element using `i` and find the remaining two elements using `left` and `right`.

- `i`: Fixes the first element.
- `left`: Points to the next element after `i`.
- `right`: Points to the last element.

Calculate:

```java
sum = nums[i] + nums[left] + nums[right];
```

### Steps

1. Sort the given array in ascending order.
2. Create an empty list `ans` to store unique triplets.
3. Traverse the array using `i` from index `0` to `nums.length - 3`, since at least two elements must remain after `i`.
4. Skip duplicate first elements using `nums[i] == nums[i-1]`.
5. Initialize `left = i + 1` and `right = nums.length - 1`.
6. Run a loop while `left < right`.
7. Calculate the sum of three elements.
8. If `sum == 0`:
   - Add the triplet to the result.
   - Increment `left` and decrement `right`.
   - Skip duplicate left and right elements.
9. If `sum < 0`, increment `left` to increase the sum.
10. If `sum > 0`, decrement `right` to decrease the sum.
11. Continue until `left >= right`.
12. Return the list of unique triplets.

### Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> threeSum(int[] nums) {

        List<List<Integer>> ans = new ArrayList<>();

        Arrays.sort(nums);

        for (int i = 0; i < nums.length - 2; i++) {

            // Skip duplicate first elements
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;

            while (left < right) {

                int sum = nums[i] + nums[left] + nums[right];

                if (sum == 0) {

                    ans.add(Arrays.asList(
                        nums[i], nums[left], nums[right]
                    ));

                    // Move both pointers
                    left++;
                    right--;

                    // Skip duplicate left elements
                    while (left < right &&
                           nums[left] == nums[left - 1]) {
                        left++;
                    }

                    // Skip duplicate right elements
                    while (left < right &&
                           nums[right] == nums[right + 1]) {
                        right--;
                    }
                }

                else if (sum < 0) {
                    left++;
                }

                else {
                    right--;
                }
            }
        }

        return ans;
    }
}
```

## Dry Run

**Input:**
```text
nums = [-1, 0, 1, 2, -1, -4]
```

**After Sorting:**
```text
nums = [-4, -1, -1, 0, 1, 2]
index:   0   1   2  3  4  5
```

Each cell shows `index (value)`.

| i | left | right | Sum | Operation |
|---|---|---|---:|---|
| 0 (-4) | 1 (-1) | 5 (2) | -3 | Sum < 0, `left++` |
| 0 (-4) | 2 (-1) | 5 (2) | -3 | Sum < 0, `left++` |
| 0 (-4) | 3 (0) | 5 (2) | -2 | Sum < 0, `left++` |
| 0 (-4) | 4 (1) | 5 (2) | -1 | Sum < 0, `left++`; now `left == right`, loop ends |
| 1 (-1) | 2 (-1) | 5 (2) | 0 | Store `[-1, -1, 2]`, then `left=3`, `right=4` |
| 1 (-1) | 3 (0) | 4 (1) | 0 | Store `[-1, 0, 1]`, then `left=4`, `right=3`, loop ends |
| 2 (-1) | - | - | - | Duplicate of `nums[1]`, skipped |
| 3 (0) | 4 (1) | 5 (2) | 3 | Sum > 0, `right--`; now `left == right`, loop ends |

The outer loop stops at `i = 3` because `i < nums.length - 2`.

**Final Output:**
```text
[[-1, -1, 2], [-1, 0, 1]]
```

## Complexity Analysis

- **Time Complexity:** O(n²) – Sorting takes O(n log n), and the outer loop with two-pointer traversal takes O(n²).
- **Space Complexity:** O(1) auxiliary space, excluding sorting implementation space (O(log n) for Java's dual-pivot quicksort on primitives) and output storage.

## Interview Note

The most important part of this problem is handling duplicate triplets.

We skip duplicates at three places:

1. **First element:** `nums[i] == nums[i-1]`
2. **Left pointer:** `nums[left] == nums[left-1]`
3. **Right pointer:** `nums[right] == nums[right+1]`

When the sum is zero, store the triplet, move both pointers, and skip duplicates.

If the sum is less than zero, move `left` forward. If the sum is greater than zero, move `right` backward.

**Optional optimization:** since the array is sorted, once `nums[i] > 0` no three numbers starting from `i` can sum to zero, so the outer loop can `break` early.

**Recommended Approach: Sorting + Two Pointers.**
